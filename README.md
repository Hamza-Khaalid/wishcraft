# 🎉 WishCraft

**WishCraft** is a web app that helps you celebrate someone’s birthday in a personalized, fun, and creative way. It includes sweet little features like countdown timers, polaroid-style images, and a digital scrapbook to make the day extra special.

## 🌟 Features

- 🎂 Countdown timer to a specific birthday or event
- 📒 Digital scrapbook to store memories and messages
- 📸 Polaroid Maker to generate vintage-style birthday photos
- 💌 Birthday Wish feature to write and display a sweet message

> All features are implemented in a simple, beginner-friendly way using basic web tech.

## 🌐 Live Demo

👉 [WishCraft on Netlify](https://wishcraft.netlify.app/)
